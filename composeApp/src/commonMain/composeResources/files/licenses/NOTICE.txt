This derivative retains and adapts the upstream preset theme palettes,
CardGroup, ConnectedChoiceButtons, PresetThemeButton, PagerTabs and Tag
components, the filled heart vector, brand SVG paths/gradients, Tavern and
RikkaHub images, and JetBrains Mono font. Chat, drawer, settings, assistant,
provider and picker layouts reuse upstream UI code with platform and business
dependencies removed. Other pages are simplified shared Compose layouts.
Original service modules were removed during the UI redraw. MOLite now connects
to the independently licensed MOLite-core through its C ABI and a JNI adapter.
MOLite adds its own branding, default purple palette, local appearance storage,
system document pickers and core-driven UI. The upstream Git history is retained.

HugeIcons Compose stroke vectors are reused from the library used by upstream:
https://github.com/rikkahub/hugeicons-compose
